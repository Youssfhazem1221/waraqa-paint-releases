# Waraqa Paint

A painting studio for your computer, from [Waraqa](https://waraqa.art).

**Download it at [paint.waraqa.art](https://paint.waraqa.art/#download).** The site always offers the
newest version for your system.

This repository holds only the installers, under [Releases](../../releases). Each release has:

| System | File |
|---|---|
| Windows 10 or 11, 64-bit | `waraqa-paint-<version>-windows-x64.msi` (installer) or `-windows-x64-portable.zip` (no install) |
| Windows, 32-bit | `waraqa-paint-<version>-windows-x86.msi` |
| macOS 11 or newer (Apple silicon or Intel) | `waraqa-paint-<version>-macos-universal.dmg` |
| Linux, 64-bit (Ubuntu 22.04+, Debian 12+, Fedora 36+) | `.AppImage`, `.deb` or `.rpm` |

**First launch:** if Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
On a Mac, right-click Waraqa Paint and choose **Open**, then **Open** again.
